\# RESEARCHPILOT



RESEARCHPILOT is an AI-assisted research platform designed to support paper analysis, retrieval, knowledge organization, and research insight generation.



\## Features



\- PDF parsing and processing

\- RAG-based question answering

\- Keyword extraction

\- Evidence retrieval

\- Knowledge graph construction

\- Research insight generation

\- Report generation



\## Project Structure



\- `app.py` - Application entry

\- `main.py` - Main program

\- `ai\_service.py` - AI model service

\- `database\_service.py` - Database service

\- `evidence\_service.py` - Evidence retrieval

\- `insight\_service.py` - Research insight generation

\- `keyword\_service.py` - Keyword extraction

\- `knowledge\_graph\_service.py` - Knowledge graph construction

\- `pdf\_service.py` - PDF processing

\- `rag\_service.py` - Retrieval-Augmented Generation

\- `report\_service.py` - Report generation
